7/11 Online Convenience Store - images
======================================

logo.svg / logo-mark.svg
    A 7-Eleven-style logo drawn for this student project. To use the OFFICIAL logo, just save your
    files here with the SAME names (logo.svg or logo.png -> update the file names in index.html).

store-*.jpg  (store-1.jpg, store-2.jpg, store-3.jpg ...)
    Put photos of a 7-Eleven convenience store here. Every file named store-<anything>.jpg / .jpeg /
    .png / .webp is picked up automatically and shown as a fading slideshow behind the login screen.
    (Landscape photos, around 1600x900 or bigger, look best.) No code change needed - just refresh.

    (The first store-*.jpg is also used as the photo on the left panel of the login card.)

store-fallback.svg
    Illustrated storefront shown when no store-*.jpg photos are present.

Note: 7-Eleven is a registered trademark. That is fine for a classroom project, but get permission
before using the logo or store photos on a real public website.
